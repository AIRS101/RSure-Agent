# RSure-Agent

RSure-Agent 是一个基于证据链的智能推理演示系统，提供直观的交互界面展示 AI 推理过程的透明性和可靠性。

## 🌐 在线演示

访问 GitHub Pages 查看完整演示：[https://airs101.github.io/RSure-Agent/](https://airs101.github.io/RSure-Agent/)

## ✨ 特性

- 🌍 **双语支持**：中文/英文界面切换
- 🎨 **主题切换**：明亮/暗黑模式
- 📱 **响应式设计**：适配桌面和移动设备
- 🔍 **证据链可视化**：完整展示推理过程和证据关系
- 📊 **多种视图**：列表视图和网格视图
- 🎯 **案例筛选**：按领域和语言快速定位

## 🚀 本地开发

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173

## 📦 构建

```bash
cd frontend
npm run build
```

构建产物位于 `frontend/dist/` 目录。
